Tips for Success
  • Auto-Generated SKUs: Leave the SKU column empty to auto-generate unique codes (format: PROD######).
  • Unique SKUs: If providing SKUs manually, each must be unique. Duplicate SKUs will update existing products.
  • Data Validation: Ensure numeric fields contain only numbers (no currency symbols or text).
  • Empty Cells: Leave optional cells empty if not applicable.
  • Backup: Consider backing up your current inventory before bulk updates.
  • Test First: Try uploading a small file with a few products first to test the process.
